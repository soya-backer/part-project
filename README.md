# 📚 Library Management Database

## 📌 Project Overview
The Library Management Database is a SQL-based project designed to manage library operations efficiently. It stores and organizes information about books, authors, categories, members, and book borrowings.

## 🎯 Objectives
- Manage book details and prices.
- Store author information.
- Organize books into different categories.
- Maintain library member records.
- Track book borrowing and return dates.

## 🗂️ Database Tables
The project consists of five tables:

- **Category:** Stores book categories such as Fairy Tales, Fantasy, Adventure, Princess Stories, and Magical Stories.
- **Books:** Contains book titles, authors, prices, and category IDs.
- **Author:** Stores author names and their countries.
- **Member:** Maintains member details, phone numbers, and joining dates.
- **Borrowings:** Tracks which member borrowed which book, along with borrowing and return dates.
